# 🌌 Cosmopedia

Cosmopedia is a space-themed web project that presents information about the planets of our Solar System in a visually engaging and interactive format. It combines structured content, images, and audio narration to create a simple digital encyclopedia experience.

---

## 🚀 Features

* 🪐 **Planet-wise Information**

  * Dedicated sections/pages for each planet (Mercury to Neptune)
  * Includes descriptions, images, and basic facts

* 🎧 **Audio Narration**

  * Each planet includes audio playback for an enhanced learning experience

* 🌐 **Navigation System**

  * Easy navigation between planets and homepage

* 🎨 **Styled UI**

  * Clean layout using CSS
  * Organized and readable structure

* 📂 **Well-Structured Assets**

  * Separate folders for images, audio, and documentation

* 📄 **Documentation Support**

  * Includes PDF files for reference and documentation

---
